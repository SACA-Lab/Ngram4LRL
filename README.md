# N-gram vs Neural Models for Low-Resource African Languages

A research project investigating when traditional n-gram classifiers should be
preferred over fine-tuned and from-scratch neural models in low-resource text
classification settings. Experiments are conducted on the
[MasakhaNEWS](https://huggingface.co/datasets/masakhane/masakhanews) benchmark
across four agglutinative Bantu languages at controlled training-set sizes.

## Research question

> At what data scale, if any, do fine-tuned multilingual models and from-scratch
> Transformers overtake TF-IDF + traditional classifiers — and is the answer
> consistent across languages?

## Experiment tracks

| Track | Method | Models | Trials | Platform |
|-------|--------|--------|--------|----------|
| [`ngram/`](ngram/) | TF-IDF features + classical classifiers | NB, SVM, XGBoost | 252 | Modal |
| [`finetuning/`](finetuning/) | Fine-tuned multilingual Transformers | XLM-R-base, AfroXLMR-base | 168 | Colab |
| [`scratch/`](scratch/) | Transformer trained from random init | Custom 4-layer encoder | 84 | Colab |

All three tracks share the same dataset, languages, training-set sizes, random
seeds, and held-out test splits, making results directly comparable.

## Results overview

The tables below report mean weighted test F1 at each training-set size. Values
for seeded conditions are averaged over 5 seeds; the `full` column uses a single
seed. Generated by `analysis/compare.py`.

### Best per track (mean weighted test F1, averaged over 5 seeds)

| Language | N | N-gram | Fine-tuning | Scratch |
|----------|---|--------|-------------|---------|
| Luganda | 100 | **0.785** | 0.546 | 0.635 |
| Luganda | 250 | **0.852** | 0.798 | 0.728 |
| Luganda | 500 | 0.870 | **0.882** | 0.798 |
| Luganda | 750 | 0.880 | **0.887** | 0.803 |
| Luganda | full | 0.877 | **0.859**¹ | 0.822 |
| Rundi | 100 | 0.749 | **0.861** | 0.627 |
| Rundi | full | **0.897** | 0.892 | 0.826 |
| chiShona | 100 | **0.896** | 0.895 | 0.759 |
| chiShona | full | **0.935** | 0.932 | 0.873 |
| Kiswahili | 100 | 0.704 | **0.802** | 0.514 |
| Kiswahili | full | 0.825 | **0.851** | 0.744 |

¹ AfroXLMR at full Luganda underperforms n-gram SVM; see per-model detail in `analysis/compare.py`.

Bold = best method at that condition. Run `python analysis/compare.py` for the full table.

### Crossover: first N where fine-tuning beats n-gram

| Language | Crossover point |
|----------|----------------|
| Luganda | N = 500 |
| Rundi | N = 100 (AfroXLMR dominates throughout) |
| chiShona | N = 250 |
| Kiswahili | N = 100 (AfroXLMR dominates throughout) |

### Key findings

- **N-gram SVM leads at very small scales for Luganda.** It takes 500 training
  examples before fine-tuned models pull ahead — clinically relevant given that
  Luganda has only 771 total training examples.
- **AfroXLMR-base dominates Rundi and Kiswahili at all scales**, suggesting
  that African-language pretraining provides representations that TF-IDF cannot
  match even with very little data.
- **N-gram SVM matches or beats fine-tuned models on chiShona at all scales**,
  a result likely driven by chiShona's morphological regularity and the
  effectiveness of character n-grams on agglutinative structure.
- **Scratch-trained Transformers consistently underperform** both alternatives
  at every scale, confirming that ~5M random-init parameters without pretraining
  is insufficient for this task.
- **Language matters as much as method.** chiShona is well-classified by all
  approaches (F1 ≥ 0.76 at N = 100); Kiswahili is the hardest for n-grams.

## Reproducing the experiments

Each track is self-contained. Run commands from the track's subdirectory.

### N-gram baselines

```bash
cd ngram
pip install -r requirements.txt   # or: pip install -e .

# Validate pipeline locally
python scripts/run_local.py --lang lug --scale 100 --classifier naive_bayes

# Run all 252 trials in parallel on Modal
modal run modal_app/run_experiments.py

# Aggregate and generate tables
python scripts/aggregate.py
python scripts/make_tables.py
```

### Fine-tuning

```bash
cd finetuning
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Validate
bash scripts/smoke_test.sh

# Full grid (requires CUDA GPU; ~40–50 GPU-hours)
bash scripts/run_grid.sh

# Analysis
python -m scripts.aggregate
python -m scripts.figures
python -m scripts.tables
```

Or open `finetuning/colab/finetune_colab.ipynb` in Google Colab.

Slice the grid via environment variables:
```bash
MODELS=xlm-r LANGS=lug NS="100 250" SEEDS="42 123" bash scripts/run_grid.sh
```

### From-scratch transformer

```bash
cd scratch
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Train per-language tokenisers (one-time, ~4 min)
python -m scripts.train_tokenizer

# Validate
bash scripts/smoke_test.sh

# Full grid (requires CUDA GPU; ~7–15 GPU-hours)
bash scripts/run_grid.sh

# Analysis
python -m scripts.aggregate
python -m scripts.figures
python -m scripts.tables
```

Or open `scratch/colab/train_colab.ipynb` in Google Colab.

### Cross-track analysis

```bash
# From the repo root
python analysis/compare.py       # print comparison tables
python analysis/figures.py       # generate cross-track figures to analysis/figures/
```

## Dependencies

Each track has its own `requirements.txt`. The n-gram track requires only
`scikit-learn`, `xgboost`, and `datasets`; the neural tracks require PyTorch,
Hugging Face Transformers, and `datasets`.

- N-gram: Python 3.11, scikit-learn, xgboost, datasets, modal, pyyaml
- Fine-tuning: Python 3.11, torch ≥ 2.1, transformers ≥ 4.45, datasets, accelerate
- Scratch: same as fine-tuning, plus sentencepiece / tokenizers
